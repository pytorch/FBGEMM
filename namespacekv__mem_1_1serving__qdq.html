Detailed Description

Rewrites embedding rows as the values serving decodes after a rowwise N-bit publish (fbgemm FloatOrHalfToFusedNBitRowwiseQuantizedSBHalf, fp16 scale and bias), so training reads exactly what the published table serves.

Replaces row[0, dim) with a fixed point y of dequantize(quantize(.)): publishing y re-derives the same codes, scale and bias, so serving decodes y bit-for-bit. One pass is usually a fixed point; a row whose fp16 scale re-rounds needs a second. Rows with inf/nan, and rows whose decode would overflow fp16 (magnitudes near 65504), are left as they are.
